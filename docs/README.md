## 📖 常见问题

### 页码偏置如何设置？

**页码偏置** = 书籍第1页对应的PDF文件页码

例如：
- PDF 第10页是书籍第1页 → 偏置 = 10
- PDF 第15页是书籍第1页 → 偏置 = 15

### 书籍页码可以是负数吗？

可以！书籍页码可以是负数（用于摘要、前言等在正文之前的内容），但生成的 PDF 页码必须 ≥ 1。

### 如何使用结构化编辑器？

1. 在编辑页面点击"结构化编辑"标签
2. 直接在表格中编辑标题、层级、页码
3. 修改书籍页码会自动计算 PDF 页码（反之亦然）
4. 条目会自动按 PDF 页码排序
5. 支持撤销/重做 (Ctrl+Z / Ctrl+Y)

### 如何查看历史任务？

点击顶部"查看历史"按钮，可以：
- 查看所有处理过的任务
- 按状态过滤任务
- 重新编辑历史任务
- 删除不需要的任务
